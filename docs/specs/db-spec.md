# Database & Persistence Specification (Vox v2)

## 1. Scope & Architectural Invariants

### 1.1 Strict Persistence Boundary Invariant
- **Sole Data Access Layer**: The `persistence/` module is the single source of truth for all database operations.
- **Zero Raw SQL Leakage**: No SQL queries, prepared statements, or database API calls are permitted anywhere in `ipc/`, `pipeline/`, or `services/`.
- **Public Facade**: `persistence/` exposes strongly-typed async Rust functions for all domain operations (e.g. `persistence::sessions::get_turns(conn, session_id)`).

### 1.2 Connection Lifecycle & Pooling
- `VoxDb` is instantiated once during application bootstrap and held as an `Arc<VoxDb>` inside `AppState`.
- Direct `VoxDb::open(&db_path)` calls outside bootstrap and test fixtures are strictly banned.
- All IPC queries borrow the shared `&AppState.db` connection.

### 1.3 Embedded Engine: Native Turso Engine (Zero-C pure Rust)
- **Engine SSOT**: Vox utilizes the **`turso` crate** as its embedded persistence engine (native Rust async I/O over Tokio, eliminating C SQLite dependencies and single-writer lock contention via WAL / MVCC). All schema specifications and queries target Turso's native dialect and feature set (e.g., native `F32_BLOB` vectors).

### 1.4 Asynchronous Hot-Path Offload (`PersistenceEvent`)
To protect the voice hot-path latency budget (<200ms), all write operations generated by the voice pipeline are dispatched asynchronously via `mpsc::Sender<PersistenceEvent>`:

```rust
pub enum PersistenceEvent {
    SessionStarted {
        session_id: i64,
        timestamp_ms: u64,
    },
    SessionEnded {
        session_id: i64,
        timestamp_ms: u64,
    },
    TurnCompleted {
        session_id: i64,
        turn_id: u32,
        user_text: String,
        assistant_text: String,
    },
    UpdateSessionMetadata {
        session_id: i64,
        key: String,   // e.g. "title", "project_id"
        value: String,
    },
    Shutdown,
}
```

## 2. Target Database Schema

### 2.1 `projects` (Session Grouping)
Enables grouping and organizing conversation sessions.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | TEXT | PRIMARY KEY | Unique project slug/UUID (default: `'default'`) |
| `name` | TEXT | NOT NULL | User-visible display name |
| `created_at` | INTEGER | NOT NULL | Millisecond epoch timestamp |
| `updated_at` | INTEGER | NOT NULL | Millisecond epoch timestamp |

*Deletion Invariant:*
- Hard delete only. A project can only be deleted if it has zero sessions under it (enforced via `FOREIGN KEY (project_id) REFERENCES projects(id) ON DELETE RESTRICT`).

---

### 2.2 `sessions`
Represents an ongoing or historical conversation session.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | INTEGER | PRIMARY KEY | Monotonic session ID |
| `project_id` | TEXT | NOT NULL DEFAULT 'default' REFERENCES `projects(id)` ON DELETE RESTRICT | Associated project |
| `title` | TEXT | NULLABLE | Generated via `<title>` tag or user-renamed |
| `is_pinned` | BOOLEAN | NOT NULL DEFAULT FALSE | Quick access pin |
| `deleted_at` | INTEGER | NULLABLE | Soft delete timestamp (NULL if active) |
| `created_at` | INTEGER | NOT NULL | Session start millisecond epoch |
| `updated_at` | INTEGER | NOT NULL | Last turn millisecond epoch |

*Cascade & Deletion Boundaries:*
- **Soft Delete**: `UPDATE sessions SET deleted_at = ? WHERE id = ?`. Default queries filter `WHERE deleted_at IS NULL`.
- **Hard Delete**: `DELETE FROM sessions WHERE id = ?`. Cascades strictly down to `turns` and `session_compactions` (`ON DELETE CASCADE`). It does **NOT** delete extracted facts, vectors, or personal memory.

*Indexes:*
- `idx_sessions_project_updated`: `(project_id, updated_at DESC)`
- `idx_sessions_active`: `(deleted_at)`

---

### 2.3 `turns`
Stores finalized conversational turns.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | Monotonic row ID |
| `session_id` | INTEGER | NOT NULL REFERENCES `sessions(id)` ON DELETE CASCADE | Parent session |
| `turn_id` | INTEGER | NOT NULL | Monotonic turn counter within session |
| `user_text` | TEXT | NOT NULL | Finalized STT transcript |
| `assistant_text` | TEXT | NOT NULL | Finalized synthesized assistant reply |
| `created_at` | INTEGER | NOT NULL | Millisecond epoch timestamp |

*Indexes:*
- `idx_turns_session_turn`: `UNIQUE (session_id, turn_id)`

---

### 2.4 `session_compactions`
Tracks rolling compaction-of-compactions passes and retains raw outputs for rollbacks.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | Compaction run counter |
| `session_id` | INTEGER | NOT NULL REFERENCES `sessions(id)` ON DELETE CASCADE | Target session |
| `trigger_kind` | TEXT | NOT NULL | `'critical'`, `'soft'`, or `'manual'` |
| `from_turn_id` | INTEGER | NOT NULL | Starting turn ID included in slice |
| `to_turn_id` | INTEGER | NOT NULL | Ending turn ID included in slice |
| `compaction_output` | TEXT | NOT NULL | Exact JSON output string from LLM (audit, context injection & rollback) |
| `status` | TEXT | NOT NULL | `'in_progress'`, `'completed'`, or `'failed'` |
| `error_msg` | TEXT | NULLABLE | Attributed failure message |
| `created_at` | INTEGER | NOT NULL | Millisecond epoch |
| `finished_at` | INTEGER | NULLABLE | Millisecond epoch |

*Indexes:*
- `idx_compactions_session_status`: `(session_id, status)`

---

### 2.5 `personal_memory`
Evolving user knowledge document, structured for global default and future project-scoped personalization.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | Row ID |
| `project_id` | TEXT | NULLABLE REFERENCES `projects(id)` ON DELETE CASCADE | NULL for global default personal memory; project ID for project-specific memory |
| `content` | TEXT | NOT NULL | Markdown document text |
| `version` | INTEGER | NOT NULL DEFAULT 1 | Monotonic revision counter for optimistic UI locking |
| `last_consolidated_at` | INTEGER | NOT NULL | Millisecond epoch of last LLM merge |
| `updated_at` | INTEGER | NOT NULL | Millisecond epoch of last edit (manual or LLM) |

*Indexes:*
- `idx_personal_memory_project`: `UNIQUE (project_id)`

---

### 2.6 `memory_ingestion_queue` (Staging)
Temporary batch-processing staging queue for extracted facts awaiting deduplication.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | INTEGER | PRIMARY KEY AUTOINCREMENT | Ingestion job ID |
| `session_id` | INTEGER | NULLABLE REFERENCES `sessions(id)` ON DELETE SET NULL | Source session provenance |
| `compaction_id` | INTEGER | NOT NULL REFERENCES `session_compactions(id)` ON DELETE CASCADE | Source compaction provenance |
| `type` | TEXT | NOT NULL | `'personal'`, `'objective'`, `'workdone'`, `'blocker'`, `'next_step'`, `'pitfall'` |
| `text` | TEXT | NOT NULL | Raw extracted fact text |
| `status` | TEXT | NOT NULL DEFAULT 'pending' | Strongly-typed lifecycle state |
| `retry_count` | INTEGER | NOT NULL DEFAULT 0 | Max 3 retry attempts |
| `error_msg` | TEXT | NULLABLE | Last error description |
| `created_at` | INTEGER | NOT NULL | Millisecond epoch |
| `processed_at` | INTEGER | NULLABLE | Millisecond epoch |

*Strongly-Typed Rust Lifecycle Enum (`QueueStatus`):*
- `Pending` (`'pending'`): Freshly inserted from compaction.
- `Stage1Processing` (`'stage1_processing'`): Atomically claimed by Stage 1 exact Jaccard dedup batch.
- `Stage1Done` (`'stage1_done'`): Passed exact dedup, awaiting embedding.
- `Stage2Processing` (`'stage2_processing'`): Atomically claimed by Stage 2 cosine embed/dedup batch.
- `Completed` (`'completed'`): Fully committed to `memory_facts`.
- `Failed` (`'failed'`): Exceeded 3 retry attempts.

*Indexes:*
- `idx_queue_status_type`: `(status, type)`

---

### 2.7 `memory_facts`
Permanent fact registry storing deduped, active and historical facts.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | TEXT | PRIMARY KEY | Fact ID: `fact_{timestamp}_{uuid}` |
| `session_id` | INTEGER | NULLABLE REFERENCES `sessions(id)` ON DELETE SET NULL | Provenance session |
| `compaction_id` | INTEGER | NOT NULL REFERENCES `session_compactions(id)` ON DELETE CASCADE | Source compaction provenance |
| `type` | TEXT | NOT NULL | `'personal'`, `'objective'`, `'workdone'`, `'blocker'`, `'next_step'`, `'pitfall'` |
| `text` | TEXT | NOT NULL | Deduped fact text |
| `status` | TEXT | NOT NULL DEFAULT 'active' | Strictly `'active'`, `'inactive'`, or `'consolidated'` |
| `created_at` | INTEGER | NOT NULL | Millisecond epoch |
| `updated_at` | INTEGER | NOT NULL | Millisecond epoch |

*Status Values:*
- `'active'`: Currently valid fact available for retrieval or consolidation.
- `'inactive'`: Deactivated fact (superseded by newer duplicate in dedup).
- `'consolidated'`: Personal fact merged into the `personal_memory` markdown document.

*Indexes:*
- `idx_facts_status_type`: `(status, type)`
- `idx_facts_session`: `(session_id)`

---

### 2.8 `memory_facts_vectors`
Dedicated vector storage for semantic search and Stage 2 cosine deduplication. Uses denormalized metadata to enable fast pre-filtering without table joins during tool calls.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `fact_id` | TEXT | PRIMARY KEY REFERENCES `memory_facts(id)` ON DELETE CASCADE | Foreign key to fact |
| `type` | TEXT | NOT NULL | Denormalized fact type (`'objective'`, `'blocker'`, etc.) |
| `status` | TEXT | NOT NULL DEFAULT 'active' | Denormalized status (`'active'`, `'inactive'`, `'consolidated'`) |
| `project_id` | TEXT | NULLABLE | Denormalized project scope |
| `created_at` | INTEGER | NOT NULL | Denormalized timestamp for recency filtering |
| `embedding` | F32_BLOB(384) | NOT NULL | Native Turso 384-dim IEEE 754 float vector |

*Indexes:*
- `idx_vectors_filter`: `(status, type, project_id)`

---

### 2.9 `notifications`
Persistent, actionable desktop notification center.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | TEXT | PRIMARY KEY | Unique notification ID (`notif_{cat}_{id}`) |
| `category` | TEXT | NOT NULL | `'session_compaction'`, `'system_error'`, `'model_download'` |
| `title` | TEXT | NOT NULL | Card title |
| `message` | TEXT | NOT NULL | Card description / instructions |
| `status` | TEXT | NOT NULL DEFAULT 'pending' | `'pending'`, `'completed'`, `'dismissed'`, `'failed'` |
| `session_id` | INTEGER | NULLABLE REFERENCES `sessions(id)` ON DELETE CASCADE | Associated session |
| `metadata` | TEXT | NOT NULL DEFAULT '{}' | JSON payload for UI actions |
| `is_read` | BOOLEAN | NOT NULL DEFAULT FALSE | Read receipt |
| `created_at` | INTEGER | NOT NULL | Millisecond epoch |

*Indexes:*
- `idx_notifications_status_cat`: `(status, category)`

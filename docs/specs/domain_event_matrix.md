# Voice Pipeline Trigger & Event Matrix across All 4 Domains

This document provides a comprehensive, plain-English mapping of all IPC commands, internal actor events (`VoxEvent`), and system triggers across the 4 primary interaction domains in Vox:
1. **Modular Passive** (`modular/passive.rs`)
2. **Modular Push-to-Talk (PTT)** (`modular/ptt.rs`)
3. **Realtime Passive** (`realtime/passive.rs`)
4. **Realtime Push-to-Talk (PTT)** (`realtime/ptt.rs`)

---

## 3. Structural & Architectural Takeaways

1. **State Machine Invariant (SSOT):**
   - `InteractionState` is the sole source of truth.
   - `TranscriptFinal` is the universal gate for entering `Thinking` across all 4 domains.
   - `PlaybackStarted` is the universal gate for entering `Speaking` (guarded by `state == Thinking`).
   - `PlaybackFinished` is the universal gate for returning to `Ready` (guarded by `state == Speaking`).
2. **Database Persistence Decoupling:**
   - Database writes (`PersistenceEvent::TurnCompleted`) and conversation history updates (`ConversationManager::push_assistant_turn`) are strictly driven by `VoxEvent::LlmFinished`, completely independent of playback completion or underruns.
3. **No Phantom Network Activity:**
   - Realtime PTT validates speech locally before emitting `activity_start()`, preventing ghost turns and hung WebSocket server sessions.

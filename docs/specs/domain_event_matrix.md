# Voice Pipeline Trigger & Event Matrix across All 4 Domains

This document provides a comprehensive, plain-English mapping of all IPC commands, internal actor events (`VoxEvent`), and system triggers across the 4 primary interaction domains in Vox:
1. **Modular Passive** (`modular/passive.rs`)
2. **Modular Push-to-Talk (PTT)** (`modular/ptt.rs`)
3. **Realtime Passive** (`realtime/passive.rs`)
4. **Realtime Push-to-Talk (PTT)** (`realtime/ptt.rs`)

---

## 3. Structural & Architectural Takeaways

1. **State Machine Invariant (SSOT):**
   - `InteractionState` (`pipeline/state.rs`) is the sole source of truth; `transition()` is the only emitter of `state_changed` and short-circuits if `state==new_state`.
   - `TranscriptFinal` is the universal gate for entering `Thinking` (all 4 domains); empty transcript recovers to `Ready` instead.
   - `PlaybackStarted` is the universal gate for entering `Speaking` (guarded by `state==Thinking` in all `on_playback_started`).
   - `PlaybackFinished` is the universal gate for returning to `Ready` (guarded by `state==Speaking` in all `on_playback_finished`).
2. **Database Persistence Decoupling:**
   - `PersistenceEvent::TurnCompleted` + `ConversationManager::push_assistant_turn` are strictly driven by `VoxEvent::LlmFinished` (modular: `on_llm_finished` with `flush_chunker` tail; realtime: `RealtimeActor` translation), completely independent of `PlaybackFinished`/underruns.
   - `Interrupted` also persists the partial assistant turn under `peek_turn_id()` (the interrupted turn) with `stt_ms=0, ttft_ms=0` before clearing and renewing the token.
3. **No Phantom Network Activity & Encapsulated Framing:**
   - Realtime PTT validates speech locally (`StopWindowValidation` → `VAD_VALIDATION_TIMEOUT_MS=500`) before emitting `RealtimeActor::signal_speech_committed(&i16_samples)` (`realtime/ptt.rs:ptt_stop`); non-speech `is_speech==false || audio.is_empty()` is discarded locally, preventing ghost turns and hung server sessions.
   - Gemini wire framing (`activityStart`/`activityEnd`, `gemini/protocol.rs:82-87`) is encapsulated inside `RealtimeSession::commit_speech_turn` (`gemini_live.rs:828`); Deepgram's `commit_speech_turn` (`deepgram_live.rs:669`) has no such framing — the guarantee is provider-specific.
4. **Uniform Engine, Divergent Token Semantics (known asymmetries):**
   - All 4 domains share one `PlaybackEngine` and one `PREROLL_THRESHOLD_SAMPLES=12_000 (~250ms @48kHz)` gate; `PlaybackFinished` gate (`buffer empty && pending==0 && turn_armed`) is identical — in realtime `pending_synthesis_jobs` stays `0` so the condition collapses.
   - `VoxEvent::Interrupted` is **realtime-only** (emitters `gemini_live.rs:909`, `deepgram_live.rs:712`); modular barge-in calls `on_interrupt` directly from `TranscriptPartial`/`ptt_start` — the `Interrupted` arms in `modular/*::handle_event` are currently dead code.
   - `ptt_cancel` is asymmetric: realtime cancels `CancellationToken` + drains VAD window; modular sets `cancel_flag` + cancels playback without token cancel or VAD drain; neither calls `signal_interrupt()`.
   - `VoxEvent::Error` toasts only in modular (`show_toast`); realtime `on_error` emits `VoiceError` without toast.

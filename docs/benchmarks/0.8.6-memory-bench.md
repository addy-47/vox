## Benchmark Design & Test Intent

This benchmark evaluates Vox Working Memory across **all three deployment tiers** under realistic context pressure and multi-turn user speech patterns over a 50-turn dataset.

### Core Metrics Measured:
1. **Context Bounding & Invariants:**
   - Total Turns Executed (Target: 50 turns)
   - Total End-to-End LLM Tokens Processed
   - Peak & Final Context Utilization (%)
   - Zero Context Budget Violations (Hard Pass/Fail Invariant)
2. **Context Maintenance & Compaction:**
   - Synchronous Critical Compactions (Count & Succeeded/Failed)
   - Background Opportunistic Compactions (Triggered, Committed, Cancelled)
   - Inter-turn Barge-In Interrupts Handled
3. **Semantic Recall Accuracy & Decay Rate:**
   - **Planted Facts:** User Name (*Alex*), Role (*Senior System Engineer*), Favorite Language (*Rust*), App Name (*Vox*), Latency Target (*sub-500ms*), Favorite Color (*teal*), Disliked Language (*Python*).
   - **Probes Evaluated:** Evaluated on Turns 35, 36, 45, 46.
   - **Recall Accuracy (%):** Percentage of planted facts successfully retrieved after compaction cycles.

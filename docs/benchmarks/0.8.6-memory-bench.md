## Benchmark Design & Test Intent

This benchmark evaluates Vox Working Memory across **all three deployment tiers** under realistic context pressure and real-time voice pipeline execution (`Nemotron-3.5 ASR` -> `Llama 3.1 8B Remote GPU LLM` -> `Supertonic 3 TTS` -> `ConversationManager`) over a 50-turn dataset.

### Core Metrics Measured:
1. **Voice Pipeline Performance:**
   - STT Transcription Latency (`Nemotron-3.5 ASR` on 16kHz PCM audio clips)
   - TTFT (Time To First Token in ms)
   - TTFA (Time To First Audio chunk in ms)
   - Engine Memory Consumption (STT RSS, LLM RSS, TTS RSS, Peak RSS MB)
2. **Per-Turn Artifact Outputs:**
   - Saved to `outputs/0.8.6_tier2a_fix_run_<timestamp>/turn_NN/` containing `input_audio.wav`, `stt_transcript.txt`, `llm_prompt.json`, `llm_response.txt`, `tts_output.wav`.
3. **Context Bounding & Compaction Invariants:**
   - Total Turns Executed (50 turns)
   - Total End-to-End LLM Tokens Processed
   - Peak & Final Context Utilization (%)
   - Zero Context Budget Violations (Hard Pass/Fail Invariant)
4. **4-Type Barge-In Interruption Matrix:**
   - Type 1 (STT Phase Interrupt), Type 2 (LLM Phase Interrupt), Type 3 (TTS Phase Interrupt), Type 4 (Compaction Phase Interrupt).
5. **Frequent Semantic Recall Probe Scoring & RCA:**
   - Fact Recall Probes evaluated every 6 turns (Turns 6, 12, 18, 24, 30, 36, 42, 48).

## Root Cause Analysis (RCA): Tier 2A Semantic Recall Improvement & Sub-100% Analysis

### 1. Initial Defect & Fix
- Initial Tier 2A run scored 23.5% recall because background opportunistic compactions were passing a static dummy string `"[Summary of prior context: Turns 1 to X summarized prior topics.]"`.
- We updated `vox_sim_bench.rs` to execute live LLM summarization calls via `COMPACTION_SYSTEM_PROMPT` on background threads before calling `commit_opportunistic()`.

### 2. Post-Fix Verification Results
- With live LLM compactions active, Semantic Recall Accuracy increased from 23.5% to **76.5% (13 / 17 facts retained)** across 50 turns and 19 compactions.
- Critical identity facts (*Alex*, *Engineer*, *Rust*, *Vox*, *sub-500ms*) were retained across the entire 50-turn session.

### 3. RCA: Why 76.5% vs 100%?
- **LLM Summary Selective Dropping**: Under the 1,500 token context constraint, `llama3.1:8b`'s background compaction summaries prioritized high-level user identity (*Alex*, *Rust*, *Vox*) while occasionally dropping secondary negative preferences (*disliked Python*) or subtle color attributes (*teal*).
- **Compaction Cancellation during High Turn Rate**: 7 background compactions were cancelled mid-flight due to Type 4 barge-ins, causing the engine to temporarily retain raw turns before consolidating on the next turn.
